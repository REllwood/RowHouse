RowHouse is a native Mac app for building databases with grids, kanban boards, calendars, Gantt charts, dashboards, formulas and automations. It works like Airtable, but there's no server and no account, and your data stays on your Macs. Claude and Codex can work with it too.

Sync that can't conflict

Each Mac writes only its own change log, so iCloud Drive never has to guess, and "conflicted copies" never appear. Every Mac merges the others' logs with hybrid logical clocks and last-writer-wins per field, and they all reach the same result.

  • Edit anywhere, even offline. Changes merge when your Macs reconnect.
  • Different fields both survive. Two people editing one record keep both edits.
  • Automations run once. They fire only on the Mac where the change happened, or on one chosen Mac for scheduled runs and AI assistants' edits.
  • Plain, open files. JSON you can back up, inspect or version.

Ask Claude or Codex to fill it in

RowHouse comes with an MCP server. Connect it once and your AI assistant can read your bases, add and update records, and build tables and fields. Its edits sync like another Mac's, are labelled with its name, and can start your automations.

claude mcp add --scope user rowhouse -- \
  /Applications/RowHouse.app/Contents/MacOS/rowhouse-mcp

Setup for Codex and Claude Desktop is in Settings › AI Assistants.

Automations with room to grow

Start with a notification when a project is blocked. Build up to scripts that call your APIs.

const table = base.getTable("Projects");
const { records } = await table.selectRecordsAsync();
const late = records.filter(r =>
  r.getCellValueAsString("Health") === "🔴 Overdue");
await fetch("https://hooks.example.com/late", {
  method: "POST",
  body: JSON.stringify({ count: late.length })
});
output.set("late", late.length);
